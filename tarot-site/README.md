# 🔮 塔罗小屋

一个供个人使用的塔罗辅助网站：你在现实中洗牌、摸牌，网站帮你查阅牌意、管理牌阵、记录解读与备注。

- 纯静态网站（HTML + CSS + JS），**不需要任何后端或数据库**
- 所有数据（备注、自定义牌阵、图片、历史记录）保存在**你自己浏览器的 localStorage 里**，不会上传到任何服务器
- 因为数据存在浏览器本地，**换设备或清除浏览器数据会丢失记录**，建议定期用页面底部的"导出我的数据备份"功能保存一份 JSON 文件

## 功能

1. **卡牌大全**：78 张牌（22 张大阿尔卡纳 + 56 张小阿尔卡纳），每张牌标注元素属性（火/水/风/土）与对应星座/星体，附正位、逆位基本含义；可上传专属图片、编写个人备注（自动保存）。
2. **牌阵库**：预设"海伦牌阵（感情）""圣三角牌阵（事业）""凯尔特十字阵（金钱）"三个牌阵；支持新建/编辑/复制/删除自定义牌阵，可拖拽调整每个牌位的位置，也可以上传背景图或注解图辅助起阵。
3. **开始占卜**：选择牌阵、填写问题，按牌位逐一记录你实际摸到的牌与正逆位，一键生成结合牌意与个人备注的解读结果。
4. **历史记录**：保存每一次占卜的完整结果，方便日后回顾对照。

## 本地预览

无需安装任何东西，直接用浏览器打开 `index.html` 即可使用。

如果双击打开有问题（部分浏览器对本地文件的某些 API 有限制），可以用一个简单的本地服务器：

```bash
# 进入项目目录后执行任一种方式
python3 -m http.server 8000
# 然后浏览器打开 http://localhost:8000
```

## 部署到 GitHub Pages（推荐，随时随地访问）

1. 在 GitHub 上新建一个仓库，例如 `tarot-site`（公开或私有仓库均可，Pages 功能对两种仓库都支持，私有仓库需要 GitHub Pro 或以上才能开启 Pages）。
2. 把这个文件夹里的所有文件（`index.html`、`css/`、`js/`、`README.md`）上传到仓库根目录：
   - 网页操作：在仓库页面点击 **Add file → Upload files**，把文件拖进去，Commit。
   - 或者用 Git 命令行：
     ```bash
     git init
     git add .
     git commit -m "初始化塔罗网站"
     git branch -M main
     git remote add origin https://github.com/你的用户名/tarot-site.git
     git push -u origin main
     ```
3. 打开仓库的 **Settings → Pages**。
4. 在 "Build and deployment" 里，Source 选择 **Deploy from a branch**，Branch 选择 **main**，目录选择 **/(root)**，点击 Save。
5. 等待 1~2 分钟，页面顶部会出现一个链接，形如：
   `https://你的用户名.github.io/tarot-site/`
   这就是你以后随时可以打开使用的网址，可以收藏到手机浏览器主屏幕。

## 关于数据备份

- 页面底部有 **"导出我的数据备份"** 按钮，会下载一个 JSON 文件，包含你所有的备注、自定义牌阵、上传的图片和历史记录。
- 换设备或清除过浏览器数据后，用 **"导入数据备份"** 按钮选择之前导出的 JSON 文件即可恢复。
- 建议每隔一段时间导出一次，避免意外丢失。

## 后续可以自己修改的地方

- `js/data.js`：78 张牌的基础含义、元素属性，以及预设牌阵的牌位布局，都在这个文件里，可以直接改文字。
- `css/style.css`：颜色、字体、圆角等视觉样式都在这里，修改 `:root` 里的变量可以快速换配色。
- 牌意的"备注"、自定义牌阵、图片都建议直接在网页里操作（会自动存到 localStorage），不需要改代码。
